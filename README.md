# Simulateur CEE AUTOPILOT

Code public du simulateur CEE d'AUTOPILOT, édité par ATEA Énergies (bureau d'études thermiques et mandataire CEE, Mulhouse).
Ce fichier est chargé par https://autopilot-renovation.fr/simulateur-cee.

- `simulateur.js` : simulateur complet (interface, calcul des volumes en kWh cumac, 22 fiches d'opérations standardisées). Généré depuis le dépôt privé `autopilot-formation` (`l/simulateur.js`), ne pas modifier à la main.
- Aucune donnée personnelle, aucune clé ni aucun dossier dans ce dépôt. Les dossiers envoyés passent par l'API privée d'ATEA.

Estimations indicatives selon les fiches en vigueur à la date affichée dans le simulateur. Aucune prime n'est garantie.
